## What's new

- **The highlight turns off as soon as the pilot releases PTT.** Before, it stayed on for 1.5 seconds afterwards. That hold time was only needed before version 1.4.0 made updates instant.
- If you'd like a short hold, type e.g. `.rxh linger 300` (0.3 seconds). If you already set a linger value yourself, it's kept.

## Download

Download **`RxHighlighter.dll`** below and replace your existing copy while EuroScope is closed. Your list setup and settings stay the same.

If you're on an older version and don't want to update yet, typing `.rxh linger 0` gives the same result.

New to the plug-in? Follow the [setup steps in the README](https://github.com/Aster-Ker/euroscope-rx-highlighter#install).
