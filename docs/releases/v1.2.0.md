## What's new

- **Choose the callsign colour for when nobody is talking.** Type `.rxh normal R G B`, e.g. `.rxh normal 255 255 255` for white, if the callsign looks too dark. Type `.rxh normal default` to go back to EuroScope's own colours, which is still the default.
- Changing a colour now updates the list straight away.
- `.rxh status` shows the not-transmitting colour.

## Download

Download **`RxHighlighter.dll`** below and replace your existing copy. Close EuroScope first, or unload the plug-in in **OTHER SET → Plug-ins…**. Your list setup and settings stay the same.

New to the plug-in? Follow the [setup steps in the README](https://github.com/Aster-Ker/euroscope-rx-highlighter#install).
