## What's new

- **No more 1-second delay.** The callsign lights up as soon as TrackAudio reports that the pilot is talking. Before, the plug-in waited for EuroScope's once-a-second plug-in timer.
- The highlight also ends on time when the linger period runs out (default 1.5 s).

## How it works

The plug-in now receives TrackAudio's messages directly on EuroScope's own UI thread, using a hidden message window. It still never calls EuroScope from its background network thread, so it remains safe to run alongside UKCP and vFPC.

## Download

Download **`RxHighlighter.dll`** below and replace your existing copy while EuroScope is closed. Your list setup and settings stay the same.

New to the plug-in? Follow the [setup steps in the README](https://github.com/Aster-Ker/euroscope-rx-highlighter#install).
