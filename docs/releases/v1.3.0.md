## What's new

- **Callsigns are white by default when nobody is talking**, the same white as EuroScope's TAXI status. You no longer need to type `.rxh normal 255 255 255`.
- If you already set your own colour with `.rxh normal R G B`, it's kept.
- To use EuroScope's own assumed, notified and non-concerned colours instead, type `.rxh normal default`.

## Download

Download **`RxHighlighter.dll`** below and replace your existing copy while EuroScope is closed. Your list setup and settings stay the same.

New to the plug-in? Follow the [setup steps in the README](https://github.com/Aster-Ker/euroscope-rx-highlighter#install).
