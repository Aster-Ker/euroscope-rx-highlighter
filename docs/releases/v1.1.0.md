EuroScope plug-in that lights up an aircraft's callsign in your lists while that pilot is talking on frequency. It gets this from TrackAudio.

## Download

Download **`RxHighlighter.dll`** below. Then follow the [setup steps in the README](https://github.com/Aster-Ker/euroscope-rx-highlighter#install):

1. EuroScope → **OTHER SET → Plug-ins… → Load** → choose `RxHighlighter.dll`.
2. In your list's column setup, change the **Callsign** column to **RX Highlighter: Callsign (lights up on RX)**. Keep the same mouse-button functions, e.g. UKCP's "Open SRD Search".
3. Start TrackAudio. Type `.rxh test BAW123` to check the setup.

## What's in this version

- Highlights the callsign in **lists only**. Nothing is drawn on the radar, and radar tags are unchanged.
- Optional **RX** marker column.
- Connects to TrackAudio automatically and reconnects if it restarts. Falls back to the older `/transmitting` endpoint for AFV-style clients.
- Built against the same EuroScope SDK as UK Controller Plugin, and works alongside UKCP and vFPC.
- Commands: `.rxh status`, `.rxh colour R G B`, `.rxh linger MS`, `.rxh marker TEXT`, `.rxh port N`, `.rxh test CALLSIGN`.

## Known limitations

- Up to about 1 second of delay before the highlight appears, because of EuroScope's plug-in refresh timer.
- Changes the callsign's text colour. Plug-ins can't change a list row's background.
- This is the first public release. Please [open an issue](https://github.com/Aster-Ker/euroscope-rx-highlighter/issues) if something doesn't work in your EuroScope setup.
